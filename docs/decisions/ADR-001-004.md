# Accepted architecture decisions

## ADR-001 Primary user and future family authorization — ACCEPTED
Single-user initial experience. Model explicit grants and revocation, never implicit household access.

## ADR-002 Encrypted local storage and controlled cloud sync — ACCEPTED
Encrypt locally; cloud sync must be controlled and consented. E2EE versus server-readable encryption is **undecided**.

## ADR-003 Medication schedule authority — ACCEPTED
My Health verified schedule is source of truth. Imported HealthKit data cannot silently modify dosage, frequency or clinician instructions.

## ADR-004 Private TestFlight alpha — ACCEPTED
Private alpha precedes public launch; security and medication safety gates must be satisfied.
